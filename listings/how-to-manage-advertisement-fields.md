Every listing has a title, a category and photos. Everything else on the posting form is up to you: a car
marketplace needs a price and a location, a jobs board probably doesn't need photos, and a community swap site may
not want phone numbers at all. The same settings page controls what visitors see on each listing.

Both sections are on **Listings › Settings**:

1. In the admin panel, go to **Listings › Settings**.
2. Use the section menu to jump to **Form fields** or **Listing details**.
3. Switch fields on or off and click **Save changes** in the bar at the bottom.
{: .steps}

## Form fields

*Title, category and photos are always on. Choose the other fields on the post-a-listing form.*

| Setting | What it does |
| --- | --- |
| **Description** | The listing's main text. When it is on, sellers must fill it in. |
| **Price** | A price field. Listings are shown in the currency and format you set in [Currency and price format](/how-to-currency-format/). |
| **Location** | Lets sellers pick one of your [locations](/how-to-add-locations/). Turn it off if your marketplace serves one town only. |
| **Phone** | A phone number, with a country selector (its starting country is **Country** in **Settings › General**). |
| **Address** | A street address. With [maps](/how-to-configure-Google-Map-Settings/) set up, sellers can place a pin and the listing gets a map. |
| **Website** | A link to the seller's website. |
| **Upload file** | Lets buyers attach a file when they contact the seller through the contact form. Hidden while the Messaging add-on is on, because messages don't take attachments. |
| **Number of Images** | The most photos per listing. Set 0 to remove photos from the form. *Your plan allows up to N.* — you can't go above your plan's limit. |

Need more than this, like mileage, number of rooms or a salary? Click **Add custom fields** under the list, or see
[Custom fields](/how-to-create-custom-fields/).
{: .tip}

Switching a field off hides it on the form for new listings. Existing listings keep what sellers already entered.
{: .note}

## Listing details

*What visitors see and can do on a listing page.*

| Setting | What it does |
| --- | --- |
| **Contact Form** | Shows a form on each listing so buyers can write to the seller. The message goes to the seller by email, or into their inbox when the [Messaging add-on](/how-to-use-messaging-system/) is on. |
| **Require Login to Contact** | Only signed-in members can contact sellers. With Messaging on, contacting always needs an account. |
| **Price on Contact Form** | Adds a **Price** field so buyers can make an offer. Only works when **Price** and the Messaging add-on are both on. |
| **Require Login to View Listing** | Visitors can browse lists of listings, but must sign in to open a listing. For a whole members-only site, use [Private site](/private-site/) instead. |
| **Count Visits Listings** | Counts views of each listing and shows the number on the listing page, in **All listings** and in the sellers' **Stats**. It also enables *Popular Listings Last Month* on the home page. |
| **Show Sharing Buttons** | A **Share** button so visitors can pass the listing on. |
| **Show Report this Listing Button** | A **Report** button. See [Reported listings](/flag-ad-inappropriate/). |
| **Show QR Code** | A QR code of the listing's address, handy for printed flyers. |
| **Show Free Tag** | Shows *Free* instead of a price when the price is 0 or empty. |
| **Rich Snippets** | Adds product details (structured data) to each listing page so search engines can show price and photo in results. See [SEO for your marketplace](/seo-classifieds-website/). |

### Contact settings that work together

- A buyer can only contact a seller about a **published** listing.
- If you turn **Contact Form** off, buyers need another way to reach sellers, such as the **Phone** field or a
  WhatsApp number in [user custom fields](/users-custom-fields/).
- Messages from the contact form go through your [email settings](/general-email-configuration/); if sellers say
  they never get them, see [Emails aren't arriving](/troubleshooting-email-errors/).

## Settings that live elsewhere

Some things you see on a listing page are switched on in other places:

| Feature | Where |
| --- | --- |
| Map on the listing and on the posting form | [Maps](/how-to-configure-Google-Map-Settings/) |
| Comments (Disqus, Facebook) | [Comments on listings and posts](/how-to-activate-comments-with-disqus/) |
| Reviews and star ratings | [Reviews and ratings](/review-system-works/) |
| Buy now button | [Let members sell with checkout](/pay-directly-from-ad/) |
| Favourites (the heart) | Always on for signed-in members. See [Favourites](/add-chosen-ads-favourites/) |
| The look of the page | Your [theme](/how-to-change-theme/) and its [theme options](/theme-options/) |
