Every image you upload while writing a page, a blog post, an FAQ answer or a forum description is kept in your
**image library**. From there you can see all of them at once, copy an image's address to use it again, and delete
the ones you no longer need.

Listing photos that members upload are not part of the library; they belong to their listings. Their size, quality
and watermark are set further down the same page: see [Photos](/how-to-configure-image-settings/) and
[Watermark your photos](/how-to-add-a-watermark/).

## Upload an image

Images get into the library from the editor:

1. While editing a page, post, question or forum, click where the image should go.
2. Click the picture button in the editor's toolbar and choose a file from your computer.
{: .steps}

The image is uploaded, added to the library and placed in your text. Click it in the editor to resize it (100%,
50% or 25%), float it left or right, or remove it from the text.

Images must be in one of the formats allowed under **Allowed Image Formats** and no bigger than
**Max. Image Size** (both in **Media › Listing photos**). If an upload is refused, the message tells you which rule
it broke.

## Manage the library

In the admin panel, go to **Media**. The **Image library** at the top shows every image with its file name and how
many there are.

| Action | How |
| --- | --- |
| See it full size | Click the image; it opens in a new tab. |
| Reuse it | Click the copy button under the image to copy its address, then paste the address where you need it, for example in the editor's picture dialog (**Image URL**) or in your [custom CSS](/how-to-use-custom-css/). |
| Delete it | Click the bin button and confirm. |

Deleting an image from the library deletes the file itself. Every page, post or email that still shows it will
show a broken image instead. Removing an image from a page in the editor does not delete it from the library.
{: .warning}

## Tips

- Resize photos before you upload them. A picture 1,600 pixels wide is plenty for a full-width image and loads
  much faster than one straight from a camera.
- Give files meaningful names before uploading, such as *how-to-post-step-1.jpg*. The library keeps the name (with
  a number added in front), which helps you find the image later and helps search engines.
- Delete test images once a page is finished, so the library stays easy to browse.
